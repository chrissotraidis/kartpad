## Current gate state

G6 is **Pass**. The portable contract is green on arm64 and x86_64/Rosetta, stateful translated fixtures pass under sanitizers, scheduled translated execution preserves CPU/FPSCR state across yields and callbacks, and every one of the 10,836 C++ units emitted from the exact pinned Mario Kart Wii DOL compiles against the portable shim. Later game or ghost divergence attributable to semantics reopens this gate immediately.

## Oracle boundary

The estimate corpus is regenerated by compiling the locked Dolphin implementation directly, then compared byte-for-byte with `fixtures/g6/dolphin-estimates.txt`. No game data is used. Conservative flags are target-local: `-fno-fast-math -ffp-contract=off`.

## Resolved mismatches

- The first upward-rounding conversion returned 2 instead of 3 because optimized host `nearbyint` did not honor a dynamically changed environment at that call site. Guest rounding is now selected explicitly with `trunc`/`ceil`/`floor`/nearest, independent of ambient host optimization.
- Initial hand-entered `Force25Bit`, fres/frsqrte, and scale-vector expectations were wrong. The implementation was held fixed; expectations were corrected only after applying the upstream algorithm by inspection or compiling pinned Dolphin's oracle.
- Leak detection is unavailable in this macOS ASan runtime. The sanitizer run now disables only unsupported leak detection; ASan and UBSan remain enabled.

## Real-title surface inventory

The read-only WBFS extractor wrote only `private/game-extract/sys/main.dol`; its SHA-256 is `80d18895b39c63bd80f457398bfcbb91b7d16ac116a41a88967e954080155b05`, identical to the immutable WiiCompiled project pin. The recursive translator used the bundled 29,792-entry function map and rejected unsupported reachable instructions. Discovery reached 802 functions directly, added 10,034 valid speculative map functions, and emitted 10,836 translation units.

The compile pass forced ownership of the emitted state-free ABI, CR/XER, time-base, reservation, string, byte-reverse, scalar/paired FP, stack/dynamic/resolved PSQ, memory-range, GX FIFO, system-register, and indirect-call shapes. Run `./scripts/test-g6-real-dol-surface.sh` after privately extracting the matching user-owned DOL.
