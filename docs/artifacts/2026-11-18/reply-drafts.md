> Sharik7, thanks, that's a really useful find, and the log came through this time.
>
> The auto-accelerate latch does almost no work itself, so I don't think it slows the game directly. What changes is that your finger is off the screen. Many phones, Xiaomi included, run the processor faster while you're touching the screen and slow it down when you stop, and your Poco needs that speed for races.
>
> One quick test would confirm it: lock the gas, then rest a finger on an empty part of the screen for a lap. If the frame rate stays good, that's the cause. If you use Game Turbo, adding KartPad there may also help.
>
> The next version also records processor speed and how long it's been since you touched the screen, so a log from it will show this directly.
>
