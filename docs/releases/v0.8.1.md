KartPad 0.8.1 fixes two problems in 0.8.0: characters that disappeared on some Snapdragon phones, and Mac builds that refused most disc images. It also fixes choosing a game folder on iPhone and iPad.

| You want KartPad on | How |
|---|---|
| **Android** | Download `KartPad-v0.8.1-android.apk` below |
| **iPhone or iPad** | Build it with [PadMint](https://github.com/chrissotraidis/padmint/releases/latest) on a Mac, Windows or Linux computer |
| **Mac** (Apple Silicon) | Build it with [PadMint](https://github.com/chrissotraidis/padmint/releases/latest): choose Mario Kart Wii and **This Mac** |

Don't install `KartPad-v0.8.1-ios-for-padmint.ipa` yourself: it has no game in it. PadMint downloads it and adds the game from your own disc.

Full steps: **[Get KartPad](https://github.com/chrissotraidis/kartpad#get-kartpad)**.

### Fixed

- **Android: invisible characters on some Snapdragon phones.** 0.8.0 switched every Adreno 6xx/7xx GPU (Snapdragon 8 Gen 3 and older) to an experimental graphics path in **Automatic**, which hid the characters on phones that showed them before. **Automatic** works as it did in 0.7.15 again. If you switched **Help → Character Graphics Test** to a **Compare** option to get characters back, switch it back to **Automatic (recommended)**: the Compare options are slow.
- **Mac: "disc-image SHA-256 is unsupported".** Building the Mac app with PadMint only accepted one exact disc image file. Any PAL (RMCP01) disc image whose game files are unmodified now works, whether it's an ISO or a WBFS.
- **iPhone and iPad: choosing the game folder in Files could do nothing after Open (#380).** **Import from Extracted Folder…** now opens a picker that only chooses folders, and always tells you whether the import worked.

### New test option

- **Android: Help → Character Graphics Test → Experimental: matrix rows like Dolphin.** For Snapdragon 8 Gen 3 and older phones where characters have always been invisible (#104, #301): it reads character bones the way Dolphin does. It's off unless you choose it, and we don't know yet whether it helps; if you try it, tell us on GitHub.

### Updating

- **Android:** tap **Update available → Update Now** on the game chooser, or install the APK over your current KartPad; don't uninstall first. Saves and game data stay.
- **iPhone and iPad:** build 0.8.1 with PadMint and install over your current KartPad with the same sideloading tool and Apple ID to keep your saves. Your game pack from 0.8.0 still fits.
- **Mac:** build 0.8.1 with PadMint 0.5.1 or newer (**This Mac**). It replaces the old app; your saves stay.

**You still need your own Mario Kart Wii** (PAL, RMCP01, revision 0). No disc images, game files or keys are included.
