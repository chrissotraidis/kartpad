KartPad 0.8.10 (build 275) fixes custom GPU drivers on Android after 0.8.9.

### Fixed

- **A driver chosen in an earlier version switched on by itself (Android):** 0.8.9 made custom GPU drivers load. That also made any driver chosen in 0.8.6–0.8.8 run for the first time the moment you updated, without warning, because until then it had never run. On some phones, such as the Snapdragon 8 Elite, that meant a striped picture or the error "Device lost: vkMapMemory failed with VK_ERROR_MEMORY_MAP_FAILED". On the first start after updating, KartPad now names the chosen driver and offers **Use Phone's Driver**.
- **A driver that fails during play now falls back (Android):** if graphics fail while a custom driver is in use, the error message says the driver is the likely cause, and the next start uses the phone's own driver. Before, this only happened when graphics failed at start-up.
- **Playing again after "Graphics Unavailable" (Android):** tapping Play right after that message stopped with "cannot change translated function profile after finalization". The next start is now clean.

If the picture looks wrong on 0.8.9 now, open **⋯ → Graphics & Performance → GPU Driver** and choose **Phone's Driver (Default)**.

### Updating

- **Android:** install the new APK over 0.8.9, or use **Update available → Update Now**. Don't uninstall first. Your game data, saves, Retro Rewind and ghosts stay.
- **iPhone, iPad and Mac:** nothing changes in this version.
