KartPad 0.8.3 (build 265) supports Retro Rewind 6.13.3.

### Changed

- **Retro Rewind 6.13.3:** KartPad compiles the new Retro Rewind game code and downloads the official 6.13.3 pack. Retro WFC only accepts the current pack. Retro Rewind's own `version.txt` in this release still reads 6.13.2; KartPad expects that and checks the exact pinned game code, XML and download.
- **Android:** short touch taps are no longer lost when two parts of the game read the same press. The game window stays fullscreen when SDL tries to restore windowed mode after the system bars hide ([#202](https://github.com/chrissotraidis/kartpad/issues/202), still to be confirmed on an AYN Thor). The vertex repack does the same work with less CPU time ([#470](https://github.com/chrissotraidis/kartpad/issues/470); no FPS change is claimed). The runtime also carries a developer-only bone-index experiment for invisible characters; it isn't selectable in the app yet.
- **iPhone and iPad:** the game chooser shows **Update needed** for an older installed Retro Rewind pack instead of **Ready to play**; Set Up Game then updates it in the app.
- **Mac builds:** setup keeps using PadMint's own Python instead of switching to another Python on PATH ([#475](https://github.com/chrissotraidis/kartpad/issues/475)).
- **Runtime:** every platform gains the double-precision fused floating-point operations the new Retro Rewind code uses. Without them the game code could not be built.

### Updating

- **Android:** **Update available → Update Now**, or install the APK over your current KartPad. Then choose **Set Up Game** on the Retro Rewind card to download the 6.13.3 pack (about 1.9 GB; about 4.2 GB free space is needed while it installs). Saves, licenses and ghosts stay.
- **iPhone, iPad and Mac:** build 0.8.3 with the latest [PadMint](https://github.com/chrissotraidis/padmint/releases/latest) and install it over your current KartPad. Mac players reuse their imported game data; see the [Mac instructions](../INSTALL_MACOS.md).

### Checked and remaining limits

Android emulator: the signed release app installed over 0.8.2 with all 6,082 app files unchanged. The in-app installer replaced Retro Rewind 6.13.1 with 6.13.3 from the official download. Retro Rewind and Original both reached races that were driven past the first minute with no crash markers; the existing license loaded, and Retro WFC signed in ("Welcome to Retro WFC").

iPhone 14: the private 0.8.3 build installed in place over 0.8.2 after a verified backup; saves, licenses and settings were unchanged, and the chooser showed **Update needed** for the phone's older Retro Rewind pack. Gameplay on the iPhone was not driven in this check.

Mac: PadMint's clean player check (Apple Python 3.9, empty PadMint folder) built 0.8.3 with the new setup step; the packaged app passed its audit and deep signature check.

Not checked: online races on 6.13.3, physical Android phones, iPhone gameplay, and performance. No FPS change is claimed.
