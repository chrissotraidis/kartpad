# KartPad 0.5.3 source delivery

KartPad 0.5.3 builds on [0.5.1](v0.5.1-source.md) and [0.5.2](v0.5.2-source.md); rebuild
instructions and dependency manifests are unchanged.

All three apps were compiled from `838214b` (the parent of the commit that adds this file)
with runtime pins Android `8deed05`, iOS `3a688ad`, macOS `e481a03` and tvOS `686a573`,
all public on `chrissotraidis/wiicompiled`. Android uses the RVZ-capable disc reader rebuilt
from the pinned Dolphin revision `4f8af23` with the patches under `patches/`.

Code changes since 0.5.2: paired-single float loads/stores keep the page-table fast path on
checked-access hosts (`runtime/include/isa/ppc_isa_quantized.h`), an opt-in all-draws mode for the
Android vertex repack, and single Joy-Con input handling/logging in
`apple/mobile/KartPadPhysicalControllers.mm`.
