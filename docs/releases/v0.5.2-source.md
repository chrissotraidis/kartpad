# KartPad 0.5.2 source delivery

KartPad 0.5.2 is a hotfix on top of [0.5.1](v0.5.1-source.md); the rebuild instructions,
dependency manifests and retained dependency sources are unchanged from 0.5.1.

Compilation sources:

- Android 0.5.2 (code 230): `a92d3289a1431c7fa7d95bf980348d966bef1942`, Android runtime
  `3bb89c55262ba9cc7a7096613b6f66d74d740196`, disc reader rebuilt from the pinned Dolphin revision
  `4f8af23db516d8b6e9cd00e7b261a65b026514a8` with the patches under `patches/`.
- iPhone/iPad 0.5.2 (build 86): the commit that adds this file (see the embedded build manifest), iOS runtime
  `b043d5cc39c6c34cad142e4de6b04a16128a86b2`, diagnostics NO.

The only code change from 0.5.1 is the viewport depth clamp in `aurora-main/lib/gfx/common.cpp`
(all three runtimes) and the Android disc reader rebuild. Both commits are public on
`chrissotraidis/kartpad` and `chrissotraidis/wiicompiled`. Generated game translation, disc
images, saves and signing identities are not included; regenerate them from your own game data.
