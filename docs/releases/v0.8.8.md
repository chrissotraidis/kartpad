KartPad 0.8.8 (build 273) updates Retro Rewind to 6.13.5, which Retro WFC now requires, and adds Shake with a Controller on Android, iPhone and iPad.

### Fixed

- **Retro Rewind, "Invalid pack version" (error 22010) and Retro Rewind not installing:** Retro Rewind released 6.13.5, and Retro WFC now turns away 6.13.4. KartPad 0.8.7 could only install 6.13.4, so a fresh install stopped and an existing one couldn't sign in. KartPad 0.8.8 is built for 6.13.5. Retro Rewind's game code changed in this update, and KartPad compiles that code into the app, so this needs the new KartPad; reinstalling the pack alone doesn't help ([#547](https://github.com/chrissotraidis/kartpad/issues/547), [#548](https://github.com/chrissotraidis/kartpad/issues/548)).
- **Android, 30 FPS Races in Retro Rewind:** Retro Rewind sets the race frame rate a second time from its own code, which moved in 6.13.5. KartPad now follows the new location, so the option still keeps Retro Rewind races at 30 FPS.

### New

- **Shake with a Controller (Android, iPhone, iPad):** **Controls → Shake to Trick…** has a new switch. With it on, shaking the phone still presses D-pad Up while a controller is connected, for clip-on controllers without motion sensors. Tilt steering stays off while a controller is connected. Off by default ([#546](https://github.com/chrissotraidis/kartpad/issues/546)).

### Updating

- **Android:** install the new APK over 0.8.7, or use **Update available → Update Now**. Don't uninstall first. Then open Retro Rewind's card; KartPad downloads the 6.13.5 full pack (about 1.9 GB). Your saves, Retro Rewind saves and ghosts stay.
- **iPhone and iPad:** build 0.8.8 with the latest [PadMint](https://github.com/chrissotraidis/padmint/releases/latest) and install it over your current KartPad with the same sideloading tool and Apple ID. Then set up Retro Rewind 6.13.5 from its card.
- **Apple Silicon Mac:** build 0.8.8 through PadMint (**Mario Kart Wii → This Mac**) and replace your current app. PadMint prepares the 6.13.5 files; see the [Mac guide](../INSTALL_MACOS.md#retro-rewind).

### Checks

- **Retro Rewind 6.13.5 pins:** the official full pack (1,939,393,404 bytes), its `Code.pul` and Riivolution XML match the hashes in the build profile, and the Retro WFC payload is unchanged. KartPad's builder translated the new code into 3,979 Retro Rewind functions (4,139 for 6.13.4).
