# KartPad 0.5.1 — Android, iPhone/iPad and Mac

**Prepared, not yet published.** Packages: Android **0.5.1 / code 229**,
iPhone/iPad **0.5.1 / build 85**, and Mac **0.5.1 / build 85**. Each is a full, clean
build from one source revision; the exact revision and hashes are recorded at
publication.

## What's new

**Smoother play**

- Graphics preparation at launch. KartPad now compiles the graphics it has recorded
  before you race and shows **Preparing graphics: X of Y** in the top-left corner while it
  works. Racing before it finishes may stutter briefly.
- Menus and courses remember the graphics they use and prepare them during loading.
- The bundled graphics list now covers more courses, including Star Cup.
- During a race, a graphic that is still compiling no longer freezes the game. It
  can be missing for a frame or two instead. The first two seconds of a race and all
  menus still wait, so thumbnails and loading images stay complete.
- After an iPadOS/iOS or macOS update, KartPad refills the system's graphics cache once
  in the background. This fixes the stutter that appeared after the iPadOS 26.7 update.
- Online: waiting for data from the server no longer freezes the game. Only the
  part of the game waiting for the network pauses.
- Android: less CPU work per frame and steadier frame delivery. Phones with 6 GB of
  memory or more prepare more graphics at launch.

**Controls**

- **Controller auto-accelerate** (#319). Hold A for one second to lock acceleration
  and press A again to release it. It is off by default. Android: Controls → Controller
  Button Mapping. iPhone/iPad: in the settings panel next to Touch auto-accelerate.
- **Single Joy-Con** (#324). A Joy-Con held sideways works as a controller on
  iPhone/iPad and Android. On Android, Controller Button Mapping can correct button
  positions if they differ on your phone. A left and right pair combined by iOS works as
  one controller.

**Stability and fixes**

- Android: fixes a launch crash on older Adreno drivers such as the ROG Phone 7S (#321).
- Android 9/10 phones compile graphics in the background (#320).
- Shared fixes: Item Rain crash, sleep timers, depth (z-fighting), controller input
  leaking through the exit prompt, empty saves, console identity setup, socket send errors
  and orderly fatal shutdown.
- Android: RVZ game images can be imported.
- New launcher look: a sun/moon theme toggle and matching game buttons.

**Experimental: broken characters on Snapdragon phones** (#104, #193, #211, #316, #308)

Android → Getting Started → Character Graphics Test → **Experimental: fix broken
characters (Snapdragon)**. Fully close and reopen KartPad after choosing it. This is an
experimental fix and is off by default. If it helps, or makes things worse, please tell
us on the issue and include a diagnostic export.

## Updating

- **Android:** install the new APK over 0.5.0. **Do not uninstall or clear app data.** Your
  game image, saves and settings stay in place. It uses the same signing key as 0.5.0.
  It cannot replace private test builds signed with a different key.
- **iPhone/iPad:** sign the unsigned IPA with the same identity and bundle identifier as
  your current install and install it over the existing app. This keeps your data.
- **Mac:** replace the app. Your data is kept in Application Support.

Game images and the Retro Rewind asset pack are not included.

## Known limitations

- The Snapdragon character fix has not been confirmed on an affected phone.
- Low-end phones (Helio G85, Kirin 710 and similar) are still well below 60 FPS.
- PowerVR BXM GPUs still cannot start the game (#304).
- A crash when entering the trophy ceremony after a cup (#131, #323) is unresolved.
  The new crash logging records the archive involved.
- A course or menu seen for the first time can still pause briefly while its graphics
  compile (once per course).
- iPad: the Select a Cup screen can drop to about 20 FPS for a moment. Races are not
  affected.
- Controller auto-accelerate and Joy-Con support have not been tested with every
  controller.
