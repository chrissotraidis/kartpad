## On every platform (Android, iPhone/iPad, Mac)

- **Graphics are prepared at launch.** KartPad compiles the graphics it has recorded
  before you race and shows **Preparing graphics: X of Y** in the top-left corner.
  Racing before it finishes may stutter briefly.
- **Menus and courses prepare their graphics while loading**, and the bundled list now
  covers more courses, including Star Cup.
- **Races no longer freeze on a new effect.** From two seconds into a race, a graphic
  that is still compiling can be missing for a frame or two instead of stopping the game.
  Menus and race starts still wait, so thumbnails and loading images stay complete.
- **Online play no longer stalls while waiting for the server.** Only the part of the
  game waiting on the network pauses.
- **Faster game engine work:** quicker disc reads and decompression, cheaper graphics
  command processing, and course-scoped graphics replay.
- **Stability fixes from WiiCompiled:** Item Rain crash, stuck sleep timers, flickering
  surfaces (z-fighting), controller input leaking through the exit prompt, empty saves
  treated as missing, console identity setup, network send errors and a clean shutdown
  after a fatal error. The app also checks the game code before launching.

## Android only

- **Fixes a launch crash on older Adreno drivers**, such as the ROG Phone 7S (#321).
- **Android 9 and 10 phones compile graphics in the background** instead of on the game
  thread (#320).
- **Less CPU work per frame and steadier frame pacing.** Uses the Android performance
  hint on Android 13+. Phones with 6 GB of memory or more prepare more graphics at launch.
- **Controller auto-accelerate** (#319): **••• → Controls → Controller Button Mapping…**.
  Hold A for one second to lock acceleration and press A again to release it. Off by default.
- **Single Joy-Con held sideways** (#324). Controller Button Mapping can correct button
  positions if they differ on your phone.
- **Better crash logging:** crash logs now record the last game files and scenes, app
  lifecycle, memory and network state.
- **New launcher look:** sun/moon theme button and matching game buttons.
- **Experimental: broken characters on Snapdragon phones** (#104, #193, #211, #316, #308).
  On the game chooser, tap **Help → Character Graphics Test… → Experimental: fix broken
  characters (Snapdragon)**, then fully close and reopen KartPad. Off by default and not
  yet confirmed on an affected phone. Please report whether it helps.

## iPhone and iPad only

- **Fixes the menu and race stutter after the iPadOS 26.7 update.** After an iOS/iPadOS
  update, KartPad refills the system's graphics cache once in the background.
- **Controller auto-accelerate** (#319): **••• → Controls → Touch Control Settings… →
  Controller auto-accelerate**. Hold A for one second to lock, press A again to release.
- **Single Joy-Con held sideways** works as a controller (#324). A left and right pair
  combined by iOS already worked and still does.
- **New launcher look:** sun/moon theme button and matching game buttons.

## Mac only

- The same graphics cache refill after a macOS update.
- No Mac-specific controls changes in this release. Joy-Con pairs and other controllers
  work as before.

## Sending a diagnostic report

- **Android:** on the game chooser, tap **Help → Export Private Diagnostics…**, then
  attach the saved file to a GitHub issue after reviewing it.
- **iPhone/iPad:** **••• → Report a Problem…**.
- **Mac:** **Help → Report a Problem…** in the menu bar.

## Updating

- **Android:** install the new APK over 0.5.0. **Do not uninstall or clear app data.** Your
  game image, saves and settings stay in place. It cannot replace private test builds
  signed with a different key.
- **iPhone/iPad:** sign the unsigned IPA with the same identity and bundle identifier as
  your current install and install it over the existing app. This keeps your data.
- **Mac:** replace the app. Your data is kept in Application Support.

Game images and the Retro Rewind asset pack are not included.

## Known limitations

- **All:** a course or menu seen for the first time can still pause briefly while its
  graphics compile (once per course). The crash when entering the trophy ceremony after a
  cup (#131, #323) is unresolved.
- **Android:** if **Help → Renderer Validation** is On, the game closes when a race loads (#325). Turn it Off; it is only a diagnostic setting. RVZ import is not included in this build (#314); convert RVZ to ISO first. The Snapdragon character fix helps characters on at least one phone but vehicles can still be broken (#102). Low-end phones (Helio G85,
  Kirin 710 and similar) are still well below 60 FPS. PowerVR BXM GPUs still cannot start
  the game (#304).
- **iPad:** the Select a Cup screen can drop to about 20 FPS for a moment. Races are not
  affected.
- **Controllers:** auto-accelerate and single Joy-Con support have not been tested with
  every controller.
