KartPad 0.8.9 (build 274) fixes some long-running issues: custom GPU drivers now actually load on Snapdragon phones, the start-up flicker on iPhone and iPad is gone, and memory no longer builds up over several cups. It also adds driver downloads and shake sensitivity, and brings the iPhone and iPad menus in line with Android's.

### Fixed

- **Android, custom GPU drivers never loaded (0.8.6–0.8.8):** a driver chosen in **⋯ → Graphics & Performance → GPU Driver** quietly fell back to the phone's own driver every time, while the menu kept showing the one you chose. If you tried Turnip before, it didn't run. It loads now, and if a driver ever doesn't, the GPU Driver row, the driver list and problem reports say so and why ([#554](https://github.com/chrissotraidis/kartpad/issues/554), [#301](https://github.com/chrissotraidis/kartpad/issues/301), [#104](https://github.com/chrissotraidis/kartpad/issues/104)).
- **Flicker while the game starts:** while the Wii safety screen faded out, KartPad showed black frames between the game's own, so the screen flickered on many iPhones and iPads. Android had the same overlap. The game's frames now stay on screen on both ([#390](https://github.com/chrissotraidis/kartpad/issues/390)).
- **Slow motion after several cups:** KartPad kept textures and compiled shaders from every course you'd raced until you restarted it. On a test setup, eight races on different cups in a row grew KartPad's memory by about 250 MB on 0.8.8 and still climbing; on 0.8.9 it stops growing after the second race. On Android and iPhone/iPad ([#510](https://github.com/chrissotraidis/kartpad/issues/510), [#339](https://github.com/chrissotraidis/kartpad/issues/339)). If a phone still slows down after a long session, it's most likely heat; **30 FPS Races** halves the work per second.
- **30 FPS Races slowed Retro Rewind's menus too:** with the option on, Retro Rewind's title screen and menus also ran at 30 FPS. Now only races change; menus stay at 60. On Android and iPhone/iPad.

### New

- **Download a driver (Android, Snapdragon):** **GPU Driver → Add Driver… → Download a Driver…** lists recent Turnip and Qualcomm driver packages from K11MCH1's, whitebelyash's and Weab-chan's releases and installs the one you pick. **Install from a .zip File…** still takes a package you downloaded yourself.
- **Shake sensitivity (Android, iPhone, iPad):** **Controls → Shake to Trick…** has **Sensitivity**: Low, Standard, High and Very High. Standard is unchanged; higher counts a lighter shake ([#553](https://github.com/chrissotraidis/kartpad/issues/553)).
- **Same menus on iPhone, iPad and Android:** iPhone and iPad get **Graphics & Performance** with **30 FPS Races** and **Simpler Computer Karts**, and **Multiplayer → Country…** for the flag and globe position shown online. Multiplayer now has the same rows in the same order on both, and every in-game menu matches row for row. Graphics Engine, GPU Driver and Graphics Diagnostics stay Android-only.
- **Same report wording everywhere:** on iPhone and iPad, **Report a Problem…** now says **Save Diagnostic Log…**, like Android. Logs now record whether 30 FPS Races and Simpler Computer Karts are on and the frame rate each race and menu started at; Android logs also record battery level.

### Updating

- **Android:** install the new APK over 0.8.8, or use **Update available → Update Now**. Don't uninstall first. Your game data, saves, Retro Rewind and ghosts stay. If you tried a custom driver before, check **⋯ → Graphics & Performance → GPU Driver** after updating.
- **iPhone and iPad:** build 0.8.9 with the latest [PadMint](https://github.com/chrissotraidis/padmint/releases/latest) and install it over your current KartPad with the same sideloading tool and Apple ID.
- **Apple Silicon Mac:** nothing changes for the Mac in this version, so rebuilding is optional.

Retro Rewind stays on 6.13.5; there's nothing to download for it.

### Checks

- **Update path (Android emulator, new device):** the published 0.8.8 APK imported an extracted game folder and reached a Grand Prix race. The 0.8.9 APK then installed over it, kept the game data and save, and reached a race at 60 FPS.
- **Custom drivers (Android emulator):** Stable Turnip v2 went from failing at its first loading step to loaded on both graphics engines. The emulator has no Adreno GPU, so graphics then fail as expected and the next start returns to the phone's driver with a message. Download a Driver listed live releases and installed Turnip v26.0.0 R8.
- **Start-up flicker:** on the iPhone 18 Pro Simulator, black frames during the fade dropped from 60 a second to none after the game's first frame. On the Android emulator, start-up black frames dropped from about 120 to 3, all before the first game frame.
- **Memory (Android emulator, release APK):** eight Grand Prix first races on different cups, run the same way on the published 0.8.8 and on 0.8.9. From the second race to the eighth, native memory went 205 → 312 MB on 0.8.8 and 129 → 103 MB on 0.8.9, with texture memory flat and normal rendering.
- **30 FPS Races:** Original races run at 30 FPS on both Android engines; Retro Rewind's menus stay at 60 and its races run at 30 on the Android emulator and the iPhone 18 Pro Simulator.
- **Menus:** every in-game menu compared row by row on the Android emulator and the iPhone 18 Pro Simulator; Country… saves the chosen country on iPhone.
- **External display (Android emulator):** a simulated 1080p display mirrored the game live and kept doing so; removing it left the game running.
- **Release files:** the Android APK is signed with KartPad's release key, and two derivations from the same bundle are byte-identical. All six files pass PadMint's audit with the same accepted findings as 0.8.8 (translated game code in the APK, and the translator's own marker and test fixtures in the source). The repository suite passes (391 tests).
- **PadMint player checks (before tagging):** passed for iPhone/iPad, Mac and Android from current PadMint `main`, with Apple's Python 3.9 and an empty PadMint folder, against the merge commit.
- **Real phone (Pixel 9 Pro XL, Google Tensor):** 0.8.9 installed over 0.8.7 without uninstalling and kept the game data. It reached a Grand Prix race at 60 FPS on the WiiCompiled 0.9 (Beta) engine, then raced eight cups in a row: native memory went 270 → 131 MB and total memory stayed about 2.0 GB. This was the release APK's contents signed with the development key that phone's earlier install used.
- **Not checked:** an iPhone, iPad or Mac running 0.8.9; Turnip on a real Snapdragon phone; the flicker fix on an affected iPhone; a live Retro WFC race.
