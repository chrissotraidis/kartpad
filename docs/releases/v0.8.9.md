KartPad 0.8.9 makes custom GPU drivers actually load on Snapdragon phones and adds driver downloads, fixes the start-up flicker on iPhone and iPad, stops memory from building up over several cups, adds shake sensitivity, and gives iPhone and iPad the same Graphics & Performance page as Android.

### Fixed

- **Android, custom GPU drivers never loaded (0.8.6–0.8.8):** a driver chosen in **⋯ → Graphics & Performance → GPU Driver** quietly fell back to the phone's own driver every time, while the menu kept showing the one you chose. If you tried Turnip before, it didn't run. It loads now, and if a driver ever doesn't, the GPU Driver row, the driver list and problem reports say so and why ([#554](https://github.com/chrissotraidis/kartpad/issues/554), [#301](https://github.com/chrissotraidis/kartpad/issues/301), [#104](https://github.com/chrissotraidis/kartpad/issues/104)).
- **Flicker while the game starts:** while the Wii safety screen faded out, KartPad showed black frames between the game's own, so the screen flickered on many iPhones and iPads. Android had the same overlap without it being reported. The game's frames now stay on screen on both ([#390](https://github.com/chrissotraidis/kartpad/issues/390)).
- **Slow motion after several cups:** KartPad kept textures and compiled shaders from every course you'd raced until you restarted it. On a test setup, eight races on different cups used about 104 MB more memory before this fix and about 20 MB after. On Android and iPhone/iPad ([#510](https://github.com/chrissotraidis/kartpad/issues/510), [#339](https://github.com/chrissotraidis/kartpad/issues/339)).

### New

- **Download a driver (Android, Snapdragon):** **GPU Driver → Add Driver… → Download a Driver…** lists recent Turnip and Qualcomm driver packages from K11MCH1's, whitebelyash's and Weab-chan's releases and installs the one you pick. **Install from a .zip File…** still takes a package you downloaded yourself.
- **Shake sensitivity (Android, iPhone, iPad):** **Controls → Shake to Trick…** has **Sensitivity**: Low, Standard, High and Very High. Standard is unchanged; higher counts a lighter shake ([#553](https://github.com/chrissotraidis/kartpad/issues/553)).
- **Graphics & Performance on iPhone and iPad:** the same page as Android, after Display, with **30 FPS Races** and **Simpler Computer Karts**. Graphics Engine, GPU Driver and Graphics Diagnostics stay Android-only.
- **Same report wording everywhere:** on iPhone and iPad, **Report a Problem…** now says **Save Diagnostic Log…**, like Android.
- **Android logs** record battery level alongside temperature and thermal state ([#339](https://github.com/chrissotraidis/kartpad/issues/339)).

### Checks so far

- **Custom drivers (Android arm64 emulator):** Stable Turnip v2 went from failing at its first loading step to loaded on both graphics engines. The emulator has no Adreno GPU, so graphics then fail as expected, and the next start goes back to the phone's driver with a message. Download a Driver listed live releases and installed Turnip v26.0.0 R8.
- **Start-up flicker:** on the iPhone 18 Pro Simulator, black presents during the fade dropped from 60 a second to none after the game's first frame, and the recording has no bright and black frames alternating. On the Android emulator, start-up black presents dropped from about 120 to 3, all before the first game frame.
- **Memory (Android arm64 emulator):** eight Grand Prix first races on different cups, measured 30 seconds in: native memory grew 98 → 205 MB before and 75 → 96 MB after, with texture memory flat at about 50 MB and normal rendering.
- **iPhone 18 Pro Simulator:** with 30 FPS Races on, races run at 30 FPS at normal speed; with Simpler Computer Karts on, all 11 computer karts load the split-screen models; the report screen shows Save Diagnostic Log….
- **Tests:** the repository suite passes (391 passed, 1 skipped); the iOS motion tests pass with warnings as errors.
