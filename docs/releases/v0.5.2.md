## Fixes

- **Crash when a race loads with Renderer Validation on** (#325). The game asked the GPU for a
  depth range slightly outside the allowed 0–1, and validation treated it as fatal. The range is
  now clamped. Verified: 0.5.1 crashes at race load with validation on; 0.5.2 races normally.
- **RVZ import now works** (#314). 0.5.1 shipped an older disc reader built before RVZ support.
  0.5.2 includes the current reader. Verified: a Mario Kart Wii RVZ imports on a fresh install and
  plays into a race.

Everything else is the same as [0.5.1](https://github.com/chrissotraidis/kartpad/releases/tag/v0.5.1).
The release checks now reject a disc reader without RVZ support.

## iPhone/iPad build 86

The same depth-range fix, built into a fresh iPhone/iPad app. No iPhone/iPad crash from it has been
reported (the Apple release app doesn't run the graphics checks that caught it on Android), so this is a
precaution to keep the platforms in step. Nothing else changed from 0.5.1 build 85.

## Updating

- **Android:** install the APK over 0.5.0 or 0.5.1. **Do not uninstall or clear app data**; your
  game data, saves and settings stay in place.
- **iPhone/iPad:** sign the unsigned IPA with the same identity and bundle identifier as your current
  install and install it over the existing app. This keeps your data.

License notices are the same as 0.5.1 (`KartPad-v0.5.1-notices.zip`); the source for this build
is the `v0.5.2` tag and the pinned runtime branches.
