# KartPad Android 0.4.16

Code 64 rebuilds the ARM64 Android game app against the official Retro Rewind
6.12.8 archive and its updated `Code.pul`. The Android version contract and
native translated Original/Retro Rewind profiles now agree on 6.12.8.

Requires Android 9/API 28 or newer, ARM64, and Vulkan. Install over the same
public signing identity to preserve app data; never uninstall or clear storage
as an update step. The APK contains no game image, extracted game assets, saves,
or private signing material.

Package evidence and static audits are required for this release. Physical
device gameplay, GPU-specific behavior, cup completion, online play, audio, and
sustained-FPS claims remain separate acceptance gates.
