KartPad 0.8.6 (build 268) fixes PadMint builds, which had stopped for everyone after an upstream change, brings in WiiCompiled's fixes through v0.9.0, and makes the Android game code faster. Retro Rewind stays at 6.13.4.

### Fixed

- **PadMint builds work again:** since 23 October, every PadMint build of KartPad 0.8.5 stopped in preflight, usually with `WiiCompiled does not match dependencies.lock.json`, on every computer and for every output. Upstream WiiCompiled had turned one of its folders into a submodule, and KartPad's setup could no longer check out the version it pins. Setup now checks out the pinned version directly. Start a new build in PadMint; you don't need to delete anything ([#509](https://github.com/chrissotraidis/kartpad/issues/509)).
- **iPhone and iPad save restore:** choosing a backup or cancelling in **Manage Saves → Restore Save Backup…** now reaches KartPad, so the chosen `rksys.dat` is imported ([#479](https://github.com/chrissotraidis/kartpad/issues/479)).
- **iPhone and iPad Mii import:** a file of the wrong size is rejected before KartPad reads it.
- **Android diagnostic logs:** each session is labelled with the game it actually ran, so a Retro Rewind session isn't listed as Original.

### Changed

- **WiiCompiled fixes through v0.9.0:** every build now includes the reviewed engine fixes from WiiCompiled up to its latest release: a crash with unusual shader colour settings (seen on Sky Station), safer release of the game screen when the app is put in the background, matrix loads that start partway through no longer dropped, the game clock using the real date for saves and ghosts, better controller-to-player matching, and Wii Remote rumble, calibration, drift and shake fixes on Mac. A Retro Rewind translation fix stops treating 21 data words as game code. WiiCompiled 0.9.0's larger graphics-layer rewrite is not included yet ([what was ported](../artifacts/2026-10-24/wiicompiled-090-ports.md)).
- **Faster Android game code:** the game code is now compiled with a profile recorded from Original and Retro Rewind races, so the compiler optimizes the code races actually use. In emulator tests on a course outside that profile, the game thread needed about 12% less CPU per frame, and the game pack is 13% smaller. Phones held back by the game thread should run closer to full speed in busy races; this doesn't make every phone hold 60 FPS ([#339](https://github.com/chrissotraidis/kartpad/issues/339)). iPhone, iPad and Mac builds are unchanged.

### Updating

- **Android:** **Update available → Update Now**, or install the APK over your current KartPad. Don't uninstall first. Retro Rewind 6.13.4 stays installed.
- **iPhone and iPad:** build 0.8.6 with the latest [PadMint](https://github.com/chrissotraidis/padmint/releases/latest) and install it over your current KartPad with the same sideloading tool and Apple ID. The `ios-for-padmint.ipa` is an input for PadMint and does not contain game code.
- **Apple Silicon Mac:** build 0.8.6 through PadMint (**Mario Kart Wii → This Mac**) and replace your current app. Your saves stay.

### Validation scope

- **PadMint builds:** PadMint's player check (Apple's Python, an empty PadMint folder) completed fresh builds of the Android game data and the full iPhone/iPad app from a clean checkout of the fix, and of the Mac app from the release commit. The Mac app passes `codesign --verify --deep --strict`. On 0.8.5 these builds stopped in preflight.
- **Android update:** on an emulator, the release APK installed over 0.8.4 and then 0.8.5 kept all 2,083 player files byte-identical, including the save, and reached races in Original and, after the in-app download, Retro Rewind 6.13.4.
- **Android fresh install:** on a new emulator, the release APK imported an extracted game folder, created a licence and reached a race.
- **Android speed:** measured on the Android emulator with alternating cold-boot runs on a course outside the profile. No phone was measured, so the gain on your phone may differ. [Measurements and limits](../artifacts/2026-10-24/pgo-release.md).
- **Not checked:** physical Android phones, an iPhone or iPad running the PadMint-built app, and Mac gameplay. This release does not claim a graphics fix; the missing-character reports stay open.
