KartPad 0.8.6 (build 268) fixes PadMint builds, which had stopped for everyone after an upstream change, and makes the Android game code faster. Retro Rewind stays at 6.13.4.

### Fixed

- **PadMint builds work again:** since 23 October, every PadMint build of KartPad 0.8.5 stopped in preflight, usually with `WiiCompiled does not match dependencies.lock.json`, on every computer and for every output. Upstream WiiCompiled had turned one of its folders into a submodule, and KartPad's setup could no longer check out the version it pins. Setup now checks out the pinned version directly. Start a new build in PadMint; you don't need to delete anything ([#509](https://github.com/chrissotraidis/kartpad/issues/509)).
- **iPhone and iPad save restore:** choosing a backup or cancelling in **Manage Saves → Restore Save Backup…** now reaches KartPad, so the chosen `rksys.dat` is imported ([#479](https://github.com/chrissotraidis/kartpad/issues/479)).
- **iPhone and iPad Mii import:** a file of the wrong size is rejected before KartPad reads it.
- **Android diagnostic logs:** each session is labelled with the game it actually ran, so a Retro Rewind session isn't listed as Original.

### Changed

- **Faster Android game code:** the game code is now compiled with a profile recorded from Original and Retro Rewind races, so the compiler optimizes the code races actually use. In emulator tests on a course outside that profile, the game thread needed about 12% less CPU per frame, and the game pack is 13% smaller. Phones held back by the game thread should run closer to full speed in busy races; this doesn't make every phone hold 60 FPS ([#339](https://github.com/chrissotraidis/kartpad/issues/339)). iPhone, iPad and Mac builds are unchanged.

### Updating

- **Android:** **Update available → Update Now**, or install the APK over your current KartPad. Don't uninstall first. Retro Rewind 6.13.4 stays installed.
- **iPhone and iPad:** build 0.8.6 with the latest [PadMint](https://github.com/chrissotraidis/padmint/releases/latest) and install it over your current KartPad with the same sideloading tool and Apple ID. The `ios-for-padmint.ipa` is an input for PadMint and does not contain game code.
- **Apple Silicon Mac:** build 0.8.6 through PadMint (**Mario Kart Wii → This Mac**) and replace your current app. Your saves stay.
