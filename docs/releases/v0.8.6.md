KartPad 0.8.6 (build 268) fixes PadMint builds, which had stopped for everyone after an upstream change, gives the game your country for the online flag and globe, adds two speed options for slower Android phones and custom GPU drivers for Snapdragon phones, brings in WiiCompiled's fixes through v0.9.0, makes the Android game code faster, and lets Android players try WiiCompiled 0.9's new graphics engine. Retro Rewind stays at 6.13.4.

### New

- **Your country online:** Mario Kart Wii reads your country from the Wii's system settings, and KartPad never provided it, so online matchmaking showed no flag and put your Mii in the wrong place on the globe. KartPad now gives the game a country, the same way a Wii does: your device's region, or on Android one you choose. On Android, change it in **⋯ → Multiplayer → Country…**. Your Mii goes on the globe at your country's capital. Existing saves load as before, with no "create new save data" prompt, in Original and Retro Rewind ([#511](https://github.com/chrissotraidis/kartpad/issues/511)).
- **30 FPS Races (Android):** **⋯ → Display → 30 FPS Races** switches single-player races to the game's own 30 FPS mode, the one it uses for 3 and 4 players. The race runs at normal speed while the game draws half as often, so a phone that slows down at 60 FPS can play at full speed. Time Trials and ghost races stay at 60 FPS. Off by default ([#339](https://github.com/chrissotraidis/kartpad/issues/339), [#510](https://github.com/chrissotraidis/kartpad/issues/510)).
- **Simpler Computer Karts (Android):** **⋯ → Display → Simpler Computer Karts** gives computer karts the simpler models the game uses in split-screen. They look less detailed and their drivers don't animate; your kart, ghosts and online players are unchanged. Off by default. Thanks to [DriftDroid](https://github.com/dorPXP/driftdroid), where this idea comes from.
- **Custom GPU drivers (Android, Snapdragon):** **⋯ → Display → GPU Driver** installs a driver package (the AdrenoTools `.zip` format other Android emulators use, such as Turnip) and uses it with either graphics engine. Many Adreno graphics faults are driver bugs, and a newer driver is the only fix for those. If a driver doesn't load, or graphics can't start with it, or the game closes twice while starting, KartPad goes back to the phone's own driver by itself. Problem reports say which driver was running.
- **Choose your graphics engine on Android (beta):** WiiCompiled 0.9 replaced its graphics layer with a newer one. KartPad 0.8.6 for Android ships both. **Classic** is the default and keeps every KartPad graphics fix, including the Adreno character and track workarounds. **WiiCompiled 0.9 (Beta)** uses the new renderer. Switch in **⋯ → Display → Graphics Engine** or with **Graphics** on the KartPad start screen; the game restarts, and your saves, settings and controller assignments stay. If anything looks wrong, switch back to Classic; if the beta closes twice while starting, KartPad goes back to Classic by itself. The beta starts with shaders recorded on the menus and seven Mushroom and Flower Cup courses, and prepares every shader it has seen at launch, so other courses may pause briefly only the first time you visit them. The first time it starts after installing or updating, the beta prepares these shaders behind a "Compiling shaders" screen; on a Pixel 9 Pro XL that took about 20 seconds. Each engine keeps its own shaders, so switching engines doesn't make either one compile them again. Of KartPad's Adreno workarounds, the beta has only the native uniform buffers option in **Android Graphics Diagnostics…**; the vertex and matrix workarounds are Classic only. Phones with a Qualcomm Adreno GPU get a warning before trying it. On Android the beta now asks the display for the game's frame rate, as Classic does, and if Vulkan isn't available it stops with a clear message instead of starting without graphics. Problem reports say which engine was running. iPhone, iPad and Mac keep the classic engine for now ([what the new engine includes](../artifacts/2026-10-24/aurora-wiicompiled-layer.md)).

### Fixed

- **Android Start button under the ⋯ button:** on phones where Android reserves room for a hidden status bar, the touch Start button sat partly under the ⋯ menu button. Start now always sits just below it, in the default layout and in custom layouts.
- **After installing Retro Rewind on Android,** the install screen offers **Back to Game Selection**, where Retro Rewind is ready to play, instead of leaving you on the finished screen.
- **PadMint builds work again:** since 23 October, every PadMint build of KartPad 0.8.5 stopped in preflight, usually with `WiiCompiled does not match dependencies.lock.json`, on every computer and for every output. Upstream WiiCompiled had turned one of its folders into a submodule, and KartPad's setup could no longer check out the version it pins. Setup now checks out the pinned version directly. Start a new build in PadMint; you don't need to delete anything ([#509](https://github.com/chrissotraidis/kartpad/issues/509)).
- **iPhone and iPad save restore:** choosing a backup or cancelling in **Manage Saves → Restore Save Backup…** now reaches KartPad, so the chosen `rksys.dat` is imported ([#479](https://github.com/chrissotraidis/kartpad/issues/479)).
- **Android 9:** the game no longer stops as soon as it starts with "Runtime context failure". Android 9 ships a second copy of a system function the game uses to find its thread data, and the game code and the app were each using a different copy. Both now use KartPad's own.
- **iPhone and iPad Mii import:** a file of the wrong size is rejected before KartPad reads it.
- **Android diagnostic logs:** each session is labelled with the game it actually ran, so a Retro Rewind session isn't listed as Original.

### Changed

- **A clearer ⋯ menu:** the in-game menu has the same main list and Display page on Android, iPhone and iPad. Show FPS Counter moved into Display, next to FPS Counter Size, Aspect Ratio, Render Resolution and App Icon. On Android, the graphics engine, 30 FPS Races, Simpler Computer Karts, GPU Driver and Graphics Diagnostics have their own **Graphics & Performance** page. On/off settings now show a switch and a short description, and tapping one flips it without closing the menu; other settings show their current choice.
- **WiiCompiled fixes through v0.9.0:** every build now includes the reviewed engine fixes from WiiCompiled up to v0.9.0: a crash with unusual shader colour settings (seen on Sky Station), safer release of the game screen when the app is put in the background, matrix loads that start partway through no longer dropped, the game clock using the real date for saves and ghosts, better controller-to-player matching, and Wii Remote rumble, calibration, drift and shake fixes on Mac. A Retro Rewind translation fix stops treating 21 data words as game code. WiiCompiled 0.9.0's new graphics layer is the Android beta engine above ([what was ported](../artifacts/2026-10-24/wiicompiled-090-ports.md)). The beta engine also has WiiCompiled v0.9.1's graphics fix for a crash when a VS or online race starts, which then kept the game from starting again; that release's other changes are for US discs, its own app and its Mac build, and v0.9.2 adds a testing option.
- **Faster Android game code:** the game code is now compiled with a profile recorded from Original and Retro Rewind races, so the compiler optimizes the code races actually use. In emulator tests on a course outside that profile, the game thread needed about 12% less CPU per frame, and the game pack is 13% smaller. Phones held back by the game thread should run closer to full speed in busy races; this doesn't make every phone hold 60 FPS ([#339](https://github.com/chrissotraidis/kartpad/issues/339)). iPhone, iPad and Mac builds are unchanged.

### Updating

- **Android:** **Update available → Update Now**, or install the APK over your current KartPad. Don't uninstall first. Retro Rewind 6.13.4 stays installed.
- **iPhone and iPad:** build 0.8.6 with the latest [PadMint](https://github.com/chrissotraidis/padmint/releases/latest) and install it over your current KartPad with the same sideloading tool and Apple ID. The `ios-for-padmint.ipa` is an input for PadMint and does not contain game code.
- **Apple Silicon Mac:** build 0.8.6 through PadMint (**Mario Kart Wii → This Mac**) and replace your current app. Your saves stay.

### Validation scope

- **PadMint builds:** PadMint's player check (Apple's Python, an empty PadMint folder) completed fresh builds of the Android game data, the full iPhone/iPad app and the Mac app from a clean checkout of the release commit. The Mac app passes `codesign --verify --deep --strict`. On 0.8.5 these builds stopped in preflight.
- **Android update:** on an emulator, the 0.8.6 release candidates installed over 0.8.4 and then 0.8.5 kept all 2,083 player files byte-identical, including the save. A later two-engine candidate, installed over that, kept all 6,074 player and Retro Rewind files identical and reached Retro Rewind 6.13.4 races on N64 Toad's Turnpike with both graphics engines.
- **Android fresh install:** on new emulators, KartPad imported an extracted game folder and created a licence, and switching engines from the in-game menu and from the start screen took effect after the restart, including switching back to Classic. The WiiCompiled engine resumed its race after the app went to the background. The final APK, installed over an earlier 0.8.6 build, kept all 2,079 player files identical. With it, the WiiCompiled engine reached a VS race on Mushroom Gorge and started again cleanly afterwards, and Classic reached a Luigi Circuit race.
- **Android speed:** measured on the Android emulator with alternating cold-boot runs on a course outside the profile. No phone was measured, so the gain on your phone may differ. [Measurements and limits](../artifacts/2026-10-24/pgo-release.md).
- **Android 9:** on an Android 9 emulator, 0.8.5 stopped with "Runtime context failure" as soon as the game started, on both engines. 0.8.6 gets past that point. That emulator has no working Vulkan driver, so it then stops at "Graphics Unavailable", which a phone with Vulkan doesn't. On a newer emulator, both engines still reach races at 60 FPS with this change.
- **Country:** on an Android emulator, the game's log changed from `Can't get SimpleAddressData` to the chosen country's code and globe position (United States, Mexico and Japan). Original and Retro Rewind saves made before the fix loaded with no "create new save data" prompt, and `rksys.dat` stayed byte-identical after starting with a new country. Retro WFC sign-in worked with a country set.
- **30 FPS Races and Simpler Computer Karts:** on an Android emulator, in a VS race on Luigi Circuit, the game thread used 455 and 438 ms of CPU per second with both off, 336 ms with 30 FPS Races (about a quarter less, with the race clock at normal speed) and 294 ms with both. With both on, all 11 computer karts loaded their split-screen models in Original and Retro Rewind 6.13.4 races, and the player's kart kept its full model. No phone was measured.
- **GPU drivers:** an emulator can't run a Snapdragon driver, so only the fallback was tested. With a package selected that isn't a working driver, both engines logged the fallback and reached the title screen at 60 FPS on the emulator's own driver, and switching back to the phone's driver cleared the choice.
- **Final candidate:** installed over the previous 0.8.6 build on an emulator, it kept all 6,078 player and Retro Rewind files identical, and Classic reached Original and Retro Rewind races and the WiiCompiled engine a Luigi Circuit race.
- **Pixel 9 Pro XL:** 0.8.6 candidates installed over the KartPad already on a Pixel 9 Pro XL as updates and kept its saves and settings. On the WiiCompiled engine, Mario Kart Wii played without problems, Retro Rewind installed and signed in to Retro WFC, and the menu changes and the Start position were checked on the phone.
- **Not checked:** other Android phones (including Snapdragon phones and Android 9), a real GPU driver on a Snapdragon phone, the country flag on the online matchmaking screen (the emulator's connection dropped before a match), an iPhone or iPad running the PadMint-built app, and Mac gameplay. This release does not claim a graphics fix; the missing-character reports stay open.
