KartPad 0.8.4 (build 266) adds rumble on Android, Retro Rewind soundtrack packs, an optional touch item hold and a new test for invisible characters on Snapdragon phones. iPhone and iPad copies that still need their PadMint build now say so, and PadMint builds ride out dropped downloads.

### Added

- **Rumble on Android:** rumble never worked on Android. Controllers with their own motor now rumble. When player one's controller has no motor, such as a handheld's built-in controls, the device itself vibrates, as in Dolphin. A **Rumble** switch in **Controls → Controller Button Mapping…** is on by default and turns both off. Touch-only play doesn't vibrate ([#497](https://github.com/chrissotraidis/kartpad/pull/497)).
- **Retro Rewind soundtrack packs:** add `.brstm` files, or a soundtrack pack's `.zip`, in **Game Data & Saves → Retro Rewind Music…** on Android and iPhone/iPad. A file named like one of Retro Rewind's tracks (for example `104_N.brstm`, and `104_F.brstm` for the final lap) replaces it the next time KartPad starts, and your music stays when Retro Rewind updates. On a Mac, put the files in the `MyStuff` folder of the `RetroRewind6` folder you chose ([#441](https://github.com/chrissotraidis/kartpad/issues/441), [#499](https://github.com/chrissotraidis/kartpad/pull/499)).
- **Touch item hold** (Android and iPhone/iPad, off by default): in **Controls → Touch Control Settings**. Holding touch L for one second keeps your item held behind the kart, so you can steer and drift while trailing a shell or banana. Press L again to let go ([#473](https://github.com/chrissotraidis/kartpad/issues/473), [#500](https://github.com/chrissotraidis/kartpad/pull/500)).
- **Android graphics:** **Help → Character Graphics Test → Experimental: bone index per vertex** is a new attempt for Snapdragon phones where riders are invisible or only their heads show. It hasn't been tried on an affected phone yet, so a log with it on helps ([#104](https://github.com/chrissotraidis/kartpad/issues/104), [#498](https://github.com/chrissotraidis/kartpad/pull/498)).

### Changed

- **iPhone and iPad:** the `ios-for-padmint.ipa` on the releases page has no game code; PadMint adds it. Installed by itself, or over an older KartPad that already had game data, it used to say **Ready to play** and then stop at a PadMint message that only mentioned a Mac. Now the game cards say **Needs your PadMint build**, the message explains that PadMint runs on a Mac, Windows or Linux computer and that saves and imported game data stay, and **Help → Getting Started** starts with the PadMint step ([#494](https://github.com/chrissotraidis/kartpad/pull/494)). Copies built with PadMint are unchanged.
- **PadMint builds:** a dropped or stalled download (the Retro Rewind pack, the Retro-WFC payload, Dawn or `sse2neon.h`) is tried again up to three times instead of stopping the build with "Remote end closed connection without response". If it still fails, the message names the server and says it's a network problem ([#495](https://github.com/chrissotraidis/kartpad/pull/495)).
- **PadMint recipe:** iPhone, iPad and Android builds ask for 16 GB free instead of 60 GB, the measured need ([#490](https://github.com/chrissotraidis/kartpad/pull/490)).

Retro Rewind stays at 6.13.3.

### Updating

- **Android:** **Update available → Update Now**, or install the APK over your current KartPad. Saves, licenses, ghosts and game data stay.
- **iPhone, iPad and Mac:** build 0.8.4 with the latest [PadMint](https://github.com/chrissotraidis/padmint/releases/latest) and install it over your current KartPad with the same sideloading tool and Apple ID. Saves and game data stay.

### Checked and remaining limits

Android emulator: the signed release app installed over 0.8.3 with all 2,083 app files unchanged, and an update with Retro Rewind installed kept all 6,073 files. The update and a fresh install reached races in Original and Retro Rewind with no crash markers. With a gamepad that has no motor as player one, the device vibrated during races in both; with **Rumble** off, or with touch only, it didn't. A soundtrack pack's `.zip` imported, and the game read the replacement music file from `MyStuff` on the title screen. Touch item hold stayed held after a long press and let go on the next tap. With the bone-index option on, the characters drew.

Mac: PadMint's clean player check (Apple Python 3.9, empty PadMint folder) built 0.8.4 before tagging and again from the published release; the packaged app passed its deep signature check.

Not checked: rumble on a real handheld or a controller with its own motor, soundtrack playback by ear, the bone-index option on an affected Adreno phone, iPhone and iPad play, online races, and performance. No FPS change is claimed.
