KartPad 0.8.12 (build 278) tells Android players which graphics driver suits their phone, adds an experimental 120 FPS mode for fast Android phones, keeps the iPhone and iPad controller mapping open while you change buttons, brings two runtime fixes to the Mac, and stops custom GPU drivers on Snapdragon phones from paying for a fix that only Qualcomm's own driver needs.

### Added

- **Recommended for This Phone (Android):** **⋯ → Graphics & Performance → Recommended for This Phone** names your phone's GPU and, on Snapdragon, Qualcomm's driver build, and says what to use. On Qualcomm's 512.762 driver, which leaves characters missing, white or washed out on Adreno 6xx and 7xx phones (Galaxy S24 and S24 Ultra, OnePlus tablet, Moto G85), it recommends a Turnip driver, and **Get a Driver…** takes you to GPU Driver to download one. On other phones it recommends the phone's own driver, plus 30 FPS Races and Simpler Computer Karts if races slow down. It reads only the GPU and driver, so it can't tell how fast your phone is.
- **120 FPS Races (Experimental, Android):** **⋯ → Graphics & Performance → 120 FPS Races (Experimental)** draws an in-between frame after each of the game's frames during races, for phones with 120 Hz screens. The game itself still runs at 60, and menus are unchanged. It roughly doubles the work of drawing each frame, so it's meant for fast phones; when a phone can't keep up, KartPad drops the extra frames. Off by default. Turning it on turns off 30 FPS Races, and the other way round. If KartPad closes unexpectedly with it on (Android 11 and later), it's turned off at the next start and KartPad tells you.

### Changed

- **Controller mapping stays open (iPhone and iPad):** after you change a button in **Controller Button Mapping**, the list comes back with the new assignment, so you can change several in a row. **Done** closes it. (#575)
- **Custom GPU drivers skip the Qualcomm fixes (Android):** with a custom driver such as Turnip or PurpleVK, KartPad still treated the phone as running Qualcomm's own driver, because those drivers keep Qualcomm's ID and the Adreno name. On Snapdragon 8 Elite and other Adreno 8xx phones that meant **Automatic** repacked every draw, the slowest of the fixes, even though it's for a fault in Qualcomm's driver. KartPad now applies the automatic Qualcomm fixes only to Qualcomm's own driver, including repackaged Qualcomm driver packages. It checks the driver name the phone reports; every Qualcomm driver in players' logs so far, from Adreno 619 to 840, names itself "Qualcomm Technologies Inc. Adreno Vulkan Driver". Nothing changes with the phone's own driver. No Adreno 8xx phone has tried a custom driver without the repack yet: if meshes or textures stretch with one, choose **⋯ → Graphics & Performance → Graphics Diagnostics… → Character Graphics Test → Experimental: fix characters and track textures**. How much faster this makes a custom driver isn't measured.

### Fixed

- **Mac start-up black frames and memory:** the Mac runtime gets two fixes iPhone, iPad and Android already had: black frames no longer cover what the game is drawing at start-up (#390), and textures nothing has drawn for about ten seconds are released, with a bounded shader cache, so memory grows less over several cups (#510).

### Updating

- **Android:** tap **Update available → Update Now**, or download the APK below and install it over 0.8.11. Don't uninstall first. Your game data, saves, Retro Rewind and ghosts stay.
- **iPhone and iPad:** build 0.8.12 with the latest [PadMint](https://github.com/chrissotraidis/padmint/releases/latest) and install it over your current KartPad with the same sideloading tool and Apple ID.
- **Apple Silicon Mac:** rebuild 0.8.12 with PadMint and replace only the app; your data stays.
