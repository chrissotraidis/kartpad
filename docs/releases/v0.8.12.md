KartPad 0.8.12 (build 277) stops custom GPU drivers on Snapdragon phones from paying for a fix that only Qualcomm's own driver needs.

### Changed

- **Custom GPU drivers skip the Qualcomm fixes (Android):** with a custom driver such as Turnip or PurpleVK, KartPad still treated the phone as running Qualcomm's own driver, because those drivers keep Qualcomm's ID and the Adreno name. On Snapdragon 8 Elite and other Adreno 8xx phones that meant **Automatic** repacked every draw, the slowest of the fixes, even though it's for a fault in Qualcomm's driver. KartPad now applies the automatic Qualcomm fixes only to Qualcomm's own driver, including repackaged Qualcomm driver packages. It checks the driver name the phone reports; every Qualcomm driver in players' logs so far, from Adreno 619 to 840, names itself "Qualcomm Technologies Inc. Adreno Vulkan Driver". Nothing changes with the phone's own driver. No Adreno 8xx phone has tried a custom driver without the repack yet: if meshes or textures stretch with one, choose **⋯ → Graphics & Performance → Graphics Diagnostics… → Character Graphics Test → Experimental: fix characters and track textures**. How much faster this makes a custom driver isn't measured.

### Updating

- **Android:** tap **Update available → Update Now**, or download the APK below and install it over 0.8.11. Don't uninstall first. Your game data, saves, Retro Rewind and ghosts stay.
- **iPhone, iPad and Mac:** nothing changes in this version.
