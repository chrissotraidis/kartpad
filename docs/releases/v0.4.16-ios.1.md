# KartPad 0.4.16 for iPhone and iPad

Build 35 rebuilds the complete ARM64 game app against the official Retro Rewind
6.12.8 archive and its updated `Code.pul`. The version gate, native translated
profiles, and installer contract now agree on 6.12.8.

Requires iOS/iPadOS 16 or newer on ARM64. The public IPA is unsigned and
requires your own signing. Existing game files, saves and settings remain in
the app data container during an in-place update when the same signing identity
is used.

The app and package audits passed. This release note does not claim new
physical-device gameplay, performance, external-display, or online acceptance.
