# Android renderer correction candidate — build 121

For existing missing/stretched character and corrupted-geometry reports. This candidate corrects four demonstrated renderer defects: stale uploads across vertex-cache invalidation, draw merging across vertex-format changes, 16-bit merged-index overflow, and a quad index-loop overflow. Local regression tests and both mobile builds pass. Improvement on affected phones is not yet confirmed.

## One comparison

1. Install the APK over your existing Community Release, keeping data and saves. It uses the same community signer. If Android reports a signature mismatch, stop and report it; do not uninstall or clear data.
2. Leave **Getting Started → Character Graphics Test → Normal** selected, then fully close and reopen KartPad. This replaces the earlier original/compatibility switch comparison for this candidate.
3. Repeat the same broken scene with the same character, mode and graphics settings. Reply in your existing issue with **unchanged / improved / fixed**, phone model, Original or Retro, and confirmation of **build 121**. Include one screenshot if the defect remains or changed.
4. If it remains broken or crashes, reopen if needed and use **Help → Report a Problem → Save Diagnostic Log…** for that attempt. Review the text before attaching it. No full private ZIP, ROM, save or frame capture is requested.

This is an optimized, non-debuggable diagnostic preview; its additional checks can affect performance. It is not a claimed performance fix or universal Android fix. No intentional crash is required. Existing normal releases remain available; Android downgrades can be blocked by version codes. No automatic uploads.
