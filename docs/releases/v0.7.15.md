# KartPad 0.7.15

KartPad 0.7.15 updates Retro Rewind to 6.13.1 and includes focused save, ghost and control fixes.

| Platform | Install |
| --- | --- |
| Android | `KartPad-v0.7.15-android.apk` |
| iPhone, iPad and Mac | Build with [PadMint](https://github.com/chrissotraidis/padmint) |

## Changes

- Update Retro Rewind to 6.13.1, including the official base pack and required update. The app downloads these from Retro Rewind's servers.
- Preserve existing Retro Rewind saves and ghosts when replacing the pack on iPhone and iPad.
- Make Android save and ghost writes report failures correctly and keep recovery data available.
- Add **Cancel Pending Ghost Import** under **Help** on Android's game chooser, so a failed import can be cleared without removing saves.
- Correct compressed ghost handling in Original Mario Kart Wii. Retro Rewind ghost transfer remains separate work.
- Add separate music and game-sound controls on iPhone and iPad, with settings retained across backgrounding and relaunch.
- Correct Apple motion input when the device is held flat, while continuing to detect shake gestures.

## Updating

On Android, install the APK over your current KartPad. Do not uninstall first. The existing Community Release signing identity is retained. On iPhone, iPad and Mac, build with PadMint; install using the same Apple ID and bundle ID to retain your data. Open Retro Rewind and complete the official pack update before playing.

You still need your own Mario Kart Wii (PAL RMCP01, revision 0). Disc images, extracted game files, saves and keys are not included. The `ios-for-padmint.ipa` is the app without translated game code and is intended for PadMint.
