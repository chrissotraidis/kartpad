# KartPad 0.4.16 for iPhone and iPad

Build 36 is the corrected ARM64 game app for Retro Rewind 6.12.8. It retains
the version-locked 6.12.8 `Code.pul` and adds a guard around the translated
`StaticR.rel` error-report section-table read. Malformed or overwritten REL
metadata now follows generated cleanup instead of dereferencing an invalid
guest pointer during the post-chooser path reported in issue #196.

Requires iOS/iPadOS 16 or newer on ARM64. The public IPA is unsigned and
requires the user's own signing identity. Existing game files, saves, and
settings remain in the app data container during an in-place update when the
same signing identity is used. The attached iPhone 14 on iOS 26.6.1 accepted
the signed build in place, launched successfully, and displayed both Original
and Retro Rewind as ready. This is not iOS 27 hardware confirmation.

The IPA contains no game image, save, signing material, or private device
profile. The unsigned app, package, and release audits must pass before this
asset is published.
