KartPad 0.8.5 (build 267) updates Retro Rewind to 6.13.4 and adds the requested rumble-strength and stick-click controls on Android, plus a quicker touch item hold on Android and iPhone/iPad.

### Added

- **Android rumble strength:** in **Controls → Controller Button Mapping…**, adjust **Rumble strength** from 0% to 200%. 100% is the standard setting; lower it for gentler feedback or raise it for stronger feedback. It applies to controller motors and the device-vibration fallback for handheld controls. The existing **Rumble** switch still turns both off. Devices without amplitude control may not change physical strength.
- **L3 and R3 mappings on Android:** either stick click is now a mapping option. Map **D-pad Up — Trick / Wheelie** to L3 or R3 to trick without reaching for the D-pad. Existing mappings stay the same until you change them.

### Changed

- **Retro Rewind 6.13.4:** updated the official pack, code hashes and compiled game code together. Install the matching content through **Download / Update Retro Rewind…** after updating KartPad. Existing saves, ghosts and imported soundtrack files are preserved by the update path.
- **Quicker touch item hold:** with the optional setting enabled, hold touch L for 0.67 seconds instead of one second to keep the item held behind your kart. Tap L again to let go. This applies to Android and iPhone/iPad; touch auto-accelerate still uses one second ([#473](https://github.com/chrissotraidis/kartpad/issues/473)).

### Updating

- **Android:** **Update available → Update Now**, or install the APK over your current KartPad. Don't uninstall first. Then update Retro Rewind to 6.13.4 in KartPad.
- **iPhone and iPad:** build 0.8.5 with the latest [PadMint](https://github.com/chrissotraidis/padmint/releases/latest) and install over your current KartPad with the same sideloading tool and Apple ID. Then update Retro Rewind in KartPad. The `ios-for-padmint.ipa` is an input for PadMint and does not contain game code.
- **Apple Silicon Mac:** rebuild through PadMint, choose **Mario Kart Wii → This Mac**, and select the matching 6.13.4 Retro Rewind data produced by that build. Your saves stay.

### Validation scope

Gameplay, emulator and physical-device testing were skipped at the owner's request. This release does not claim a graphics or performance fix. Existing missing-character reports remain open. Build, package and hosted-file verification are recorded separately from gameplay acceptance.
