# KartPad 0.5.3 — Android, iPhone/iPad and Mac

Android **0.5.3 / code 231**, iPhone/iPad **0.5.3 / build 87** and Mac **0.5.3 / build 86**.

## iPhone, iPad and Mac

- **Cup select no longer drops to 20–30 FPS** (#327). The course-preview videos on the cup
  screen were decoded through a slow memory path on Apple devices. Measured on a Mac with the
  same steps before and after: Select Cup went from 29–30 FPS to a steady 60 FPS.
- **Single Joy-Con (iPhone/iPad, #324):** KartPad now listens for a lone Joy-Con through both
  of iOS's input channels, and the diagnostic report records which buttons iOS says it has, so
  if it still doesn't respond we can see why.

## Android

- **New experimental option for Snapdragon track textures** (#102). Help → Character Graphics
  Test… → *Experimental: fix characters and track textures (Snapdragon, may be slower)*. It
  applies the character fix to every draw, which may also fix the striped track and wall
  textures on phones like the Z Fold 8. It costs extra CPU, so keep the character-only option
  if it's slower for you. Fully close and reopen KartPad after choosing it.
- The same memory-path fix is included. Most Android phones already used the fast path, so
  expect little change there.

## Updating

- **Android:** install the APK over your current version. **Do not uninstall or clear app
  data.** Same signing key as 0.5.0–0.5.2.
- **iPhone/iPad:** sign the unsigned IPA with the same identity and bundle identifier as your
  current install and install it over the existing app.
- **Mac:** replace the app. Your data is kept in Application Support.

Game images and the Retro Rewind asset pack are not included.

## Known limitations

- The Snapdragon options are experimental and unconfirmed on affected phones. On the S24 Ultra
  (Adreno 750) the character fix does not help yet (#104, #193, #211).
- Single Joy-Con on iPhone is untested with real hardware.
- Low-end phones are still well below 60 FPS; PowerVR GPUs still can't start (#304); the
  trophy-ceremony crash (#131, #323) is still open.
