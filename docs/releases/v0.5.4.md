## What's new

- **Experimental: fix invisible characters (Snapdragon 8 Gen 3 / S24)** (#104, #193, #211).
  On the S24 Ultra (Adreno 750) the 0.5.1 character fix runs but characters stay invisible.
  This option combines that fix with a different way of choosing each vertex's matrix, the one
  part of the character path the earlier fix didn't touch. Help → Character Graphics Test… →
  *Experimental: fix invisible characters*, then fully close and reopen KartPad. It may be
  slower; switch back to Normal if it doesn't help.

Everything else is the same as 0.5.3.

## Updating

Install the APK over your current version. **Do not uninstall or clear app data.**

## Known limitations

- The new option is unconfirmed on an affected phone. It was checked on an Android emulator,
  where characters render correctly with it on, but the emulator has no Snapdragon GPU.
