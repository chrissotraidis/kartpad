# KartPad 0.4.13 — iPhone/iPad compatibility, chooser and diagnostics preview

Unsigned ARM64 IPA, version 0.4.13/build 29, for iPhone and iPad on iOS/iPadOS 16
or newer. This platform-specific preview does not replace the Mac, Apple TV or
Android packages. It is not an App Store or TestFlight build.

## Changes

- Physical iOS runtime and translated code now use a generic ARM64 CPU baseline
  instead of an M2 target. This removes an identified RCpc instruction dependency
  unsupported on older A10-class devices. The reported iPad startup crash still
  needs a matching original crash report and physical-device confirmation.

- The Mario Kart Wii / Retro Rewind chooser now displays the actual KartPad app
  artwork in its original colors instead of the previous generic logo.
- Problem reports add app/build, selected game, supported/installed Retro version,
  display settings and timestamps. A bounded manifest identifies exact source,
  prepared runtime and translation inputs. It does not claim dependency or binary
  identity, and the manifest contains hashes/counts rather than private filenames.
- Retains the 0.4.11 numeric console-serial correction and existing save/identity,
  touch, controller and version-locked Retro Rewind behavior.

## Install without losing data

Download `KartPad-v0.4.13-ios.1-unsigned.ipa` and `SHA256SUMS`. Verify the checksum,
re-sign with your existing identity and bundle identifier, and update in place.
Keep a backup; do not uninstall or clear the app to update. Supply your own
supported PAL RMCP01 revision 0 game image; Retro Rewind 6.12.7 installs separately.
See [the installation guide](../INSTALL_IPA.md).

## Acceptance and known limits

This preview is published under Christopher's explicit manual release request.
Physical iPhone/iPad acceptance of this exact build remains open. Check the
chooser on both devices, launch Original and installed Retro, return to the
chooser, and export a problem report. Confirm existing saves remain available.
See the [build and UI evidence](../artifacts/2026-09-09/ios-preview-build29.md).

This is not a verified fix for iPad external-display issues, Mac two-player
rendering, unmerged Mac controller/keyboard changes, Android freezes/corruption,
or reported end-of-cup crashes. It does not include Android-only CPU optimizations
or Android rating companion import. No new gameplay performance gain is claimed.

The IPA contains translated game logic and notices but no disc images, extracted
retail assets, Retro pack, saves, signing identity or provisioning profile.
GPLv3/Corresponding Source and third-party notices remain applicable; package
audits do not establish rights to redistribute game-derived code.
