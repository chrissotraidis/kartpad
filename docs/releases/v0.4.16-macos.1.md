# KartPad 0.4.16 for macOS

Build 35 rebuilds the complete native Apple Silicon app against the official
Retro Rewind 6.12.8 archive and its updated `Code.pul`. The version gate and
translated Original/Retro Rewind profiles now agree on 6.12.8.

Requires Apple Silicon and macOS 14 or newer. The app is ad-hoc signed and
contains no game data; supply your own supported files through the existing
setup. Existing settings and saves remain outside the application bundle.

The package and native helper audits passed. This release note does not claim
new physical gameplay, tearing, external-display, or online acceptance.
